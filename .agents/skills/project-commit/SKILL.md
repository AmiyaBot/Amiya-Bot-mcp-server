# 项目提交

## 能做什么

- 按 [提交执行规范](references/workflow.md) 汇总整个工作区的改动、生成覆盖全部改动的提交信息，并通过根目录 `commit-all.sh` 完成本地提交或提交并推送。

## 不能做什么

- 不得直接执行 `git commit`，也不得通过其他方式绕过项目提交脚本。
- 不得把提交授权扩大为推送授权。
- 不得因为改动不是当前 Agent 产生的、与当前任务无关或属于用户已有改动，就擅自排除、拆分或拒绝提交；用户要求提交时，工作区全部改动均属于提交范围。
