# MCP 工具说明

本服务对外暴露 4 个 MCP 工具，通过 SSE 协议提供。调用流程为 `search_operator` → `get_operator_basic` / `get_operator_skill`。

---

## 1. search_operator — 干员模糊搜索

按干员名称进行模糊搜索，返回候选干员的 `id` 和 `name`。拿到 `id` 后，再调用 `get_operator_basic` 或 `get_operator_skill`。

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | `str` | 是 | 干员名称关键词，支持模糊搜索 |

### 返回值

**成功**（有匹配）：
```json
{
  "data": {
    "operators": [
      {"id": "char_002_amiya", "name": "阿米娅"},
      {"id": "char_003_kalts", "name": "凯尔希"}
    ]
  }
}
```

**空查询**：
```json
{"message": "query 不能为空"}
```

**无匹配**：
```json
{"message": "未找到匹配的干员: xxx"}
```

### 排序规则

1. **精确匹配**（`query == name`）— 排最前，如搜索「银灰」命中「银灰」
2. **包含匹配**（`query in name`）— 其次，如「银灰」命中「凛御银灰」
3. **相似度匹配**（文本相似度 ≥ 0.2）— 最后，如「银灰」命中「灰喉」「洋灰」
4. 同类型内按匹配分数降序；最多返回 10 条

## 2. get_operator_basic — 干员卡片

根据干员 ID 获取干员基础信息与属性，附带一张干员立绘图片。

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `operator_id` | `str` | 是 | 干员 ID，由 `search_operator` 返回 |

### 返回值

**成功**：
```json
{
  "data": {
    "id": "char_002_amiya",
    "name": "阿米娅",
    "rarity": 5,
    "class": "术师",
    "type": "中坚术师",
    "position": "远程位",
    "...": "..."
  },
  "image_url": "https://..."
}
```

`data` 字段是 dict，至少包含：`id`、`name`、`rarity`、`class`、`type`、`position`。`image_url` 是生成的干员卡片图片地址。

**失败**：
```json
{"message": "查询干员信息时发生错误."}
```
或
```json
{"message": "未找到干员ID: xxx"}
```

## 3. get_operator_skill — 干员技能

根据干员 ID 获取技能数据，默认返回第 1 个技能的等级 10。本工具不生成图片。

### 参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `operator_id` | `str` | 是 | — | 干员 ID |
| `index` | `int` | 否 | `1` | 技能序号，从 1 开始 |
| `level` | `int` | 否 | `10` | 技能等级 1~10（8/9/10 对应专精一/二/三） |

### 返回值

**成功** — `data` 为 Markdown 格式的技能描述文本：
```json
{
  "data": "干员：阿米娅（Amiya）职业：中坚术师（术师）\n技能：第1个 · 战术咏唱·γ型\n等级：7\n技能范围：□□□\n■□□□\n□□□\n\n技力类型：自动回复\n触发方式：手动触发\n技力：10/32\n持续：30.0 秒\n技能效果：\n攻击速度+60"
}
```

Markdown 文本包含：干员名、技能名、等级、技能范围（文本图）、技力类型、触发方式、技力消耗、持续时间、技能效果。

**失败**：
```json
{"message": "技能序号 index 必须 >= 1（当前：0）"}
```
```json
{"message": "技能等级 level 必须在 1~10 之间（当前：0）"}
```
```json
{"message": "干员xxx没有第N个技能"}
```
```json
{"message": "查询干员技能信息时发生错误."}
```

## 4. get_glossary — 游戏术语

获取明日方舟游戏数据中指定术语的解释和计算公式。

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `glossary_name` | `str` \| `list[str]` | 是 | 术语名字符串、逗号/顿号分隔的字符串、或字符串数组 |

### 返回值

**成功** — JSON 字符串，key 为术语名，value 为解释文本：
```json
{
  "攻击力": "干员基础攻击力，计算公式为...",
  "防御力": "干员基础防御力，..."
}
```

**数据为空**（远端术语数据缺失时）：
```
{}
```

> 注意：本工具返回的是 JSON **字符串**（`str` 类型），调用方需要自行 `JSON.parse`。

---

## 调用流程

```
用户输入 "银灰"
    │
    ▼
search_operator(query="银灰")
    → {"data": {"operators": [
         {"id": "char_172_svrash", "name": "银灰"},
         {"id": "char_1045_svash2", "name": "凛御银灰"}
       ]}}
    │
    ├── 用户选择 "银灰" → get_operator_basic(operator_id="char_172_svrash")
    │       → {"data": {...}, "image_url": "..."}
    │
    └── 用户选择 "银灰" → get_operator_skill(operator_id="char_172_svrash", index=1, level=7)
            → {"data": "干员：银灰 ... 技能：强力击·γ型 ..."}
```

---

## 错误处理约定

| 场景 | 返回格式 | HTTP 状态码 |
|------|----------|-------------|
| 上下文未初始化 | `{"message": "未初始化数据上下文"}` | 200 |
| 参数校验失败 | `{"message": "具体错误描述"}` | 200 |
| 内部异常 | `{"message": "查询...时发生错误."}` | 200 |
| 工具不存在 | MCP 协议层报错 | — |

所有业务错误均通过 `message` 字段返回，不会抛出 HTTP 5xx。
